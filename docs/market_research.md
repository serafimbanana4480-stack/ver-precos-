## Análise e Recomendações

### Precisão do Modelo

O modelo XGBoost tem um desempenho **limitado** para estimar preços de carros usados em Portugal:

- **R² = 0.594**: O modelo explica apenas ~59% da variação de preços — ~41% fica inexplicada
- **MAE = €8.464**: O erro médio é de ~€8.500, muito significativo para carros de €15k-€30k
- **MAPE = 56.9%**: O erro percentual médio é muito alto — as estimativas podem variar ±57%

### Performance por Segmento

| Segmento | Tendência | Observação |
|---|---|---|
| **VW Golf** | Subestima ligeiramente | Estima ~€3k abaixo do mercado. GTIs/desportivos têm maior dispersão. |
| **BMW Série 3** | Sobrestima ligeiramente | Estima ~€3k acima do mercado para Série 3 recentes. |
| **Mercedes Classe C** | Razoável (±€1.1k) | Melhor segmento — estimativas consistentes. |
| **Renault Clio** | Sobrestima | Estima ~€1.9k acima do mercado para Clios recentes. |
| **Peugeot 208** | Sobrestima | Estima ~€2k acima do mercado para 208s recentes. |

### Recomendações

1. **Usar como referência, não como verdade** — as estimativas dão uma direção geral.
2. **Cruzar sempre com preços reais** — Standvirtual, OLX e CustoJusto.
3. **Aumentar a base de treino** — 1.078 amostras é insuficiente (ideal: 5k-10k+).
4. **Adicionar features** — incluir modelo específico, estado, extras, cor, donos.
5. **Calibração periódica** — re-treinar mensalmente com novos dados.
6. **Mostrar intervalo de confiança** — apresentar ±30-50% em vez de valor único.
